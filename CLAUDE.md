## Project Overview

Personal artist website for **TheFAB** (Fabrice Dusonchet), an independent melodic techno producer.
Stack: Flask + SQLite + Jinja2 templates + vanilla JS/CSS. No JavaScript framework.

## Project Structure

```
melodic-techno-site/
├── app.py                  # Flask app + all content data (see Content Data section below)
├── database.py             # SQLite setup: subscribers + email_logs tables
├── email_sender.py         # smtplib bulk newsletter via Gmail SMTP
├── pdf_generator.py        # ReportLab recipe PDF generation
├── build_static.py         # Renders pages to docs/ for GitHub Pages preview
├── requirements.txt
├── .env.example
├── static/
│   ├── css/style.css       # Single CSS file — dark + light theme, full design system
│   ├── js/main.js          # Theme toggle, mobile nav, flash auto-dismiss
│   ├── images/
│   │   ├── artist.jpg      # About page portrait (add to activate)
│   │   └── gear/           # Gear page photos (see Gear Images below)
│   └── downloads/recipes/  # Auto-generated recipe PDFs
└── templates/
    ├── base.html           # Shared nav (with theme toggle) + footer
    ├── home.html           # Hero with animated Moog SVG, featured track, downloads CTA
    ├── about.html          # Artist story, Moog animation, photo column
    ├── gear.html           # Studio section, 6 gear categories, Live Set section
    ├── music.html          # Track list with YouTube embeds
    ├── cooking.html        # Recipe cards
    ├── downloads.html      # Downloads listing (requires email gate cookie)

```

## Commands

**Run locally:**
```bash
cd melodic-techno-site
pip install -r requirements.txt
cp .env.example .env   # fill in ADMIN_PASSWORD, GMAIL_USER, GMAIL_APP_PASSWORD
python app.py          # dev server on http://localhost:5000
```

**Build static GitHub Pages preview:**
```bash
cd melodic-techno-site
python build_static.py
# outputs to ../docs/
```

**Git operations — always run from repo root `/home/user/testClaude/`:**
```bash
git add melodic-techno-site/ docs/
git commit -m "message"
git push -u origin claude/melodic-techno-artist-site-egx2zy
```

## Content Data (all in `app.py`)

Edit these dicts/strings to update site content without touching templates:

| Variable | Used by | Notes |
|---|---|---|
| `STUDIO_SECTION` | `gear.html` | `title`, `text`, `image` (filename or `None`) |
| `LIVE_SET_SECTION` | `gear.html` | `title`, `text_lead` (left-border block), `text_outro` (gear-instr card), `image` |
| `GEAR_CATEGORIES` | `gear.html` | List of 6 dicts; each has `id`, `number`, `title`, `tagline`, `image`, `intro`, `instruments`, `outro` |
| `TRACKS` | `music.html`, `home.html` | `title`, `original_song`, `original_artist`, `process`, `bpm`, `tags`, `youtube_id`, `featured` |
| `RECIPES` | `cooking.html` | `name`, `description`, `key_ingredients`, `filename` |
| `DOWNLOADS` | `downloads.html` | Dict of category → list of `{name, meta, icon, file}` |

### Gear images
Place photos in `static/images/gear/` and set the `image` key to the filename:
- `STUDIO_SECTION["image"]` → e.g. `"studio-setup.jpg"`
- `LIVE_SET_SECTION["image"]` → e.g. `"live-set.jpg"`
- Per-category `image` key → e.g. `"moogs.jpg"`, `"brain.jpg"`, etc.

### LIVE_SET_SECTION text structure
The Live Set section splits its text into two visually distinct blocks:
- `text_lead` — short opening paragraphs; rendered with a **left blue accent line**
- `text_outro` — the main content + poetic closing; rendered as a **bordered card** (blue top accent, matching `.gear-instr` instrument cards)

## Key Conventions

- **Single CSS file** — all styles in `static/css/style.css`. Sections are labelled. Add page-specific styles at the bottom of the relevant page section.
- **Design system components** (defined in `style.css`, use in any template):
  - `.callout` — left blue border, subtle; for lead/highlight paragraphs
  - `.callout--neutral` — adds `bg-surface` background; for info sidebars
  - `.callout--tinted` — adds faint accent wash; for closing thoughts
  - `.manifesto-lines` — mono font, wide line-height; for short artistic statements
  - `.about-sidebar` / `.about-sidebar__label` / `.about-sidebar__value` — profile info card
- **Accent color** — electric blue `#1a6bff` on near-black `#0a0a0a` background.
- **Fonts** — `Space Mono` (headings + mono labels) + `Inter` (body prose).
- **Light/dark mode** — toggle button in nav; theme stored in `localStorage` as `'theme'`; applied via `data-theme="light"` on `<html>`. Anti-flash inline script in `<head>`. Only `h1`/`h2` turn blue in light mode; `h3`/`h4` stay dark.
- **Moog SVG animation** — CSS in `style.css`. Home uses `wk`/`bk` ID prefixes, About uses `awk`/`abk` to avoid conflicts. Canvas waveform gradient is theme-aware (reads `data-theme` each frame).
- **Bot protection** — downloads gate has honeypot field (`.hp-wrap`, CSS off-screen) + HMAC-SHA256 signed timing token (`_make_form_token` / `_verify_form_token` in `app.py`). Min 3 s / max 1 h submission window.
- **Admin route** — `/admin`, not linked in nav. Password set via `ADMIN_PASSWORD` env var, hashed with Werkzeug on startup.
- **Email gate** — downloads page requires email signup; access token stored in cookie `dl_token` (1 year expiry).
- **GitHub Pages** — branch `claude/melodic-techno-artist-site-egx2zy`, `/docs` folder. Run `build_static.py` and commit `docs/` after **any** template or CSS change.
- **Artist photo** — place at `static/images/artist.jpg`; `onerror` fallback already coded in `about.html`.
