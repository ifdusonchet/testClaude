## Project Overview

Personal artist website for **TheFAB** (Fabrice Dusonchet), an independent melodic techno producer.
Stack: Flask + SQLite + Jinja2 templates + vanilla JS/CSS. No JavaScript framework.

## Project Structure

```
melodic-techno-site/
├── app.py                  # Flask app, all content data (GEAR_CATEGORIES, TRACKS, RECIPES, DOWNLOADS)
├── database.py             # SQLite setup: subscribers + email_logs tables
├── email_sender.py         # smtplib bulk newsletter via Gmail SMTP
├── pdf_generator.py        # ReportLab recipe PDF generation
├── build_static.py         # Renders pages to docs/ for GitHub Pages preview
├── requirements.txt
├── .env.example
├── static/
│   ├── css/style.css       # Full dark theme — single CSS file, no framework
│   └── downloads/recipes/  # Auto-generated recipe PDFs
└── templates/
    ├── base.html           # Shared nav + footer
    ├── home.html           # Hero with animated Moog SVG, featured track, downloads CTA
    ├── about.html          # Artist story, Moog animation, photo column
    ├── gear.html           # 6 gear categories with ~20 instruments
    ├── music.html          # Track list with YouTube embeds
    ├── cooking.html        # Recipe cards
    ├── downloads.html      # Downloads (email-gated)
    ├── downloads_gate.html # Email capture form
    └── admin/              # Login + dashboard (not linked in nav)
docs/                       # GitHub Pages static build (generated by build_static.py)
```

## Commands

**Run locally:**
```bash
cd melodic-techno-site
pip install -r requirements.txt
cp .env.example .env   # fill in ADMIN_PASSWORD, GMAIL_USER, GMAIL_APP_PASSWORD
python app.py          # dev server on http://localhost:5000
```

**Build static GitHub Pages preview:**
```bash
cd melodic-techno-site
python build_static.py
# outputs to ../docs/
```

**Git operations — always run from repo root `/home/user/testClaude/`:**
```bash
git add melodic-techno-site/ docs/
git commit -m "message"
git push -u origin claude/melodic-techno-artist-site-egx2zy
```

## Key Conventions

- **Content data lives in `app.py`** — edit `GEAR_CATEGORIES`, `TRACKS`, `RECIPES`, `DOWNLOADS` dicts to update the site without touching templates.
- **Single CSS file** — all styles in `static/css/style.css`. Page-specific sections are clearly labelled.
- **Accent color** — electric blue `#1a6bff` on near-black `#0a0a0a` background.
- **Fonts** — `Space Mono` (headings/mono elements) + `Inter` (body).
- **Moog SVG animation** — shared CSS in `style.css`. Home uses `wk`/`bk` ID prefixes, About uses `awk`/`abk` to avoid conflicts.
- **Admin route** — `/admin`, not linked in nav. Password set via `ADMIN_PASSWORD` env var, hashed with Werkzeug on startup.
- **Email gate** — downloads page requires email signup; token stored in cookie `dl_token` (1 year).
- **GitHub Pages** — branch `claude/melodic-techno-artist-site-egx2zy`, `/docs` folder. Run `build_static.py` and push `docs/` after any template or CSS change.
- **Artist photo** — place at `melodic-techno-site/static/images/artist.jpg`; `onerror` fallback is already coded in `about.html`.
